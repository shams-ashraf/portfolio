BioMed Advanced RAG Chatbot
Freelance Project · Iterative & Self-Correcting RAG over Biomedical Documents
freelance

Built an enhanced RAG pipeline for accurate Q&A over biomedical documents, moving beyond single-pass retrieval to an iterative, self-correcting loop that strictly grounds answers in source content.

Implemented a self-evaluation mechanism where the LLM grades its own answers as complete, partial or missing information, automatically triggering corrective re-retrieval and progressive context expansion until the answer holds up.

Designed multimodal retrieval with separate pipelines for text and tables, prioritizing structured table data for stronger factual grounding and filtering out low-quality chunks before they reach the model.

Engineered context-aware chunking with token-aware trimming and source-tracking, so the system reuses only the chunks it needs and stays transparent about what it actually cited.

Added short-term conversational memory via compressed chat history, plus production-oriented hardening: API key rotation, and robust retry/error handling for rate limits (429) and payload-size errors (413).
